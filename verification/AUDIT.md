## Fluid RK stage equations

The installed `zeta_direct` reconstruction evaluates
`omega_h(x_i)=sum_j Gamma_j sigma_j^-3 zeta(|x_i-X_j|/sigma_j)` at particle targets. The induced velocity is assembled pairwise from the regularized Biot-Savart interaction `u(x)=sum_j g(r_j/sigma_j) [Gamma_j x r_j]/(4*pi*|r_j|^3)`, with the source's vector orientation verified in `FLOWVPM_fmm.jl`. The Gaussian-erf basis is `zeta(r)=(2*pi)^(-3/2) exp(-r^2/2)` for dimensionless `r`.

The installed low-storage RK3 routine uses stages `(a,b)=(0,1/3),(-5/9,15/16),(-153/128,8/15)`. For each stage the source updates velocity-memory `M_U <- a M_U + dt (U+Uinf)` then `X <- X+b M_U`; forms a stretching contraction `S` from `J` and `Gamma`; updates strength-memory from `S-3Z Gamma-C sigma^3 E_SFS/zeta(0)` and applies `Gamma <- Gamma+b M_Gamma`; and updates sigma-memory from `-sigma Z` followed by `sigma <- sigma+b M_sigma`. Core spreading is applied at the RK stages. `Z` is computed from the component of stretching and SFS terms parallel to `Gamma`, with the exact contraction controlled by the `transposed` option. Particle insertion/deletion changes particle count and the represented field outside this fixed-particle ODE. This formulation-specific description is based on the installed package source; a filtered-equation F3 MMS still needs a derivation and compatible source interface.
